# 사진 지우개 (PWA)

사진 속 불필요한 대상(전선·전신주·지나가는 사람 등)을 **칠한 부분만** 지우고, 나머지는 **원본 해상도·화질 그대로** 저장하는 모바일 웹앱입니다. 사진은 휴대폰 밖으로 나가지 않습니다(모든 계산을 폰 안에서 처리).

## 주요 기능

| 구분 | 기능 |
|---|---|
| 칠해서 지우기 | 손가락으로 칠하기 / 빼기, 두 손가락으로 확대·이동, 붓 크기 조절, 실행 취소·다시 실행, 누르는 동안 원본 비교 |
| 자동 엔진 선택 | 가는 선(전선 등)은 주변 무늬 복사(PatchMatch), 덩어리(사람·물건)는 AI 채우기(MI-GAN) |
| 하늘 전선 자동 선택 | 하늘에 걸친 가는 선을 찾아 자동으로 칠함 → 다듬은 뒤 지우기 |
| 보정본으로 채우기 | 갤럭시 생성형 편집으로 지운 사진을 불러오면, 바뀐 곳을 자동으로 칠하고 **그 부분만** 보정본에서 가져옴(색 차이 자동 보정) |
| 저장 | 원본 해상도 JPEG(품질 95), 촬영 정보(EXIF)·색 프로필(Display P3 등) 유지, 옛 썸네일 제거 |
| 모바일 | 갤러리에서 **공유 → 사진 지우개**로 바로 열기(사진 2장을 함께 공유하면 원본+보정본으로 자동 인식), 오프라인 동작 |

## 설치 (안드로이드)

1. Chrome으로 앱 주소 접속
2. 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**
3. 이후 갤러리에서 사진 → 공유 → "사진 지우개"

AI 모델(약 28MB)은 처음 AI 채우기를 쓸 때 한 번 받아서 보관합니다.

## 파일 구성

- `index.html`, `style.css`, `app.js` — 화면·조작
- `worker.js` — 계산(화면이 멈추지 않도록 별도 스레드)
- `engine.js` — 알고리즘(PatchMatch 채우기, 전선 검출, 보정본 비교·합성, AI 채우기 영역 처리)
- `jpegmeta.js` — EXIF·ICC 옮겨 붙이기
- `vendor/` — onnxruntime-web 1.20.1 (MIT, Microsoft)
- `models/migan_pipeline_v2.onnx` — MI-GAN (Picsart AI Research). 코드 MIT, 가중치는 원 저장소의 라이선스를 따릅니다(개인 사용 목적).

## 배포

GitHub Pages: **Settings → Pages → Branch: `main` / `(root)`**. 코드를 고친 뒤에는 `sw.js`의 `CACHE` 버전을 올리면 설치된 앱도 다음 실행 때 갱신됩니다.

## 로컬 실행

```bash
python3 -m http.server 8080
```
서비스워커·모듈 워커 때문에 `file://`로 열면 안 되고 `localhost` 또는 HTTPS에서 열어야 합니다.
